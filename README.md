# Tributary agenda-data

Raw capture snapshots committed by the `agenda-capture` GitHub Actions cron
(every 6h): RSS prominence snapshots (`snapshots/`), daily event-universe
(`universe/`), and news-sitemap article lists (`sitemaps/`).

This branch is the public evidence base behind agenda reports and omission
claims (P6: share results). It is data-only — code lives on `main`, which
checks this branch out as its `agenda/` directory in CI. Do not rewrite
history here; published claims cite these files.
